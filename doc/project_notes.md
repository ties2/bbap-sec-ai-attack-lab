### 📝 Project Update: Integrating React Dashboard with Flask Backend

**Objective:**
Replaced the default Flask/HTML dashboard with a modern React component (`BBAP-Sec-Dashboard.jsx`) while preserving the existing backend API and the option to view the legacy dashboard.

#### 1. Frontend Setup & Build (Vite + React)
*   Initialized a Vite React project in the `frontend/` directory.
*   Moved the target component to `frontend/src/BBAP-Sec-Dashboard.jsx`.
*   **Fix:** Updated `App.jsx` to explicitly import with the `.jsx` extension to satisfy Vite's bundler: `import Dashboard from "./BBAP-Sec-Dashboard.jsx";`
*   **Fix:** Resolved build errors by installing missing third-party dependencies required by the component:
    ```bash
    npm install lucide-react recharts
    ```
*   Compiled the production-ready frontend using `npm run build`, which generated the static files in `frontend/dist/`.

#### 2. Flask Backend Integration (`app.py`)
*   Updated `webapp/app.py` to serve the pre-built React files using Flask's `send_from_directory` instead of `render_template` for the main route.
*   **Route Architecture:**
    *   `GET /`: Serves the new compiled React `index.html`.
    *   `GET /old-dashboard`: Serves the legacy Jinja template dashboard.
    *   `GET /assets/<path>`: Serves the compiled JS/CSS files generated by Vite.
    *   `GET /<path>`: A catch-all route that ignores `/api` calls but ensures React client-side routing works by falling back to `index.html`.
*   **Fix:** Resolved a `TypeError: unsupported operand type(s) for /: 'str' and 'str'` when defining the build directory path. Fixed by wrapping the custom root path function in `pathlib.Path`:
    ```python
    # Changed from:
    REACT_BUILD_DIR = get_project_root() / "frontend" / "dist"
    # To:
    REACT_BUILD_DIR = Path(get_project_root()) / "frontend" / "dist"
    ```

**Status:**
The Flask server is now successfully acting as a dual-host: handling the JSON API endpoints for running attacks/fetching results, while simultaneously serving the modern React UI on the root path.
